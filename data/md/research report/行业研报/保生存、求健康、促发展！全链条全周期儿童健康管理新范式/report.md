# 世界卫生组织（WHO）对健康的定义包括四个主要方面

# 躯体健康

指身体各系统、器官功能正常，没有疾病或虚弱状态。

![](images/8dd927fcfe7e74133d73e5af8106bcd6343bac832298f3e440abcc3a30808d43.jpg)

# 心理健康

指个体能够恰当地认识、评价自己及周围的人和事，具有和谐的人际关系，情绪稳定，行为有目的性，能够应对生活中的压力，正常学习、工作和生活。

![](images/9947aa8e0c1a5bb31684906734465fdda5e06667f403c776de26d7adbd5a85ad.jpg)

# 社会适应

指个体能够主动应对环境变化，保持个人与环境、社会及人际交往的均衡与协调。

![](images/555c1d5266e9e2f696fa478b5ddaec00abecf688f988d47ce670c096bc2cc1fc.jpg)

# 道德健康

涉及个体的道德品质，如诚实、正直和责任感。

# 新时代的儿童青少年健康管理

新时代的儿童健康管理是以预防保健为中心、以保护和促进儿童身心健康和社会适应能力为目标，根据各年龄阶段儿童的生长发育特点，提供综合性保健服务，注重健康教育、保健育儿知识、咨询服务，帮助家长掌握儿童保健知识，降低疾病的发生率和死亡率，保护儿童健康，促进儿童生长发育，促进儿童早期发展（保生存、求健康、促发展）  
儿童健康管理通过“评估-指导-干预-发展-再评估” 不断循环、递进的医教结合的保健模式，促进儿童生长发育，使儿童发挥最大的潜能，获得生理、心理和社会能力的全面发展

# 新时代的儿童青少年健康管理

与传统的儿童保健相比，儿童健康管理变被动的疾病治疗为主动的管理健康，变只关注儿童的生长发育及疾病为更关注儿童的全面发展, 特别是营养状况、膳食行为、发育行为、心理卫生及彼此之间的相互作用，期待通过儿童早期发展促进让每个儿童都有机会充分发挥自身潜能  
儿童健康管理包含健康（含生长发育）监测、健康评估、风险干预和健康促进。其中健康监测是日常工作，健康评估是基础，风险干预和健康促进是核心，而促进和改善儿童健康及促进儿童早期发展是目的  
对儿童生长发育的监测、评估和促进是其重中之重  
促进儿童早期发展是儿童健康管理重要目的
