# 肝炎早筛：拥抱肝炎防治刚需，领航市场新机遇 头豹词条报告系列

# 摘要

肝炎早筛行业针对肝炎病毒、药物性等因素导致的肝脏损伤进行早期检测与筛查，技术壁垒高，研发投入大，技术成熟度和性能指标要求严格。全球及中国市场对肝炎早筛需求巨大，市场前景广阔。中国肝炎患者数量多，知晓率和诊断率低，存在刚性需求。随着生物技术、基因测序和人工智能技术的发展，肝炎早筛技术取得显著进步。政府推动肝炎筛查覆盖率提升，肝炎筛查项目完善，单价水平提升，公众健康意识增强，市场需求将进一步扩大。2018年—2023年，肝炎早筛行业市场规模由311.65亿人民币元增长至549.19亿人民币元，期间年复合增长率 $1 2 . 0 0 \%$ 。预计2024年—2028年，肝炎早筛行业市场规模由596.52亿人民币元增长至781.42亿人民币元，期间年复合增长率$6 . 9 8 \%$ 。

# 行业定义

肝炎是指由病毒、药物、乙醇或代谢异常等因素引起的肝脏损伤所导致的炎症反应。根据病原体的不同，肝炎可分为病毒性肝炎（如甲型、乙型、丙型等）和非病毒性肝炎（如药物性和自身免疫性肝病）。据世界卫生组织预计，目前全球约有3.25亿人受到乙型和丙型病毒性肝炎的影响。同时，自身免疫性肝病在中国的发病率逐年上升，逐渐成为影响健康的重要肝病之一。考虑到肝炎的多样性及其对人类健康的严重威胁，肝炎的早期筛查显得尤为重要。

肝炎早筛行业是针对一般人群和高危人群提供早期检测与筛查的服务领域。其目标是在症状出现前，识别出可能患肝炎的人，实现早期诊断、及时干预和有效治疗，以提高治愈率，改善生活质量，并预防疾病进展至肝硬化或肝癌。“一般人群”指那些没有已知肝病风险因素或症状的普通民众，“高危人群”包括因病毒感染、长期饮酒、家族史等因素而更易患肝病的人。

# 肝炎早筛行业基于筛查方式的分类

# 病毒性肝炎标志物检测

针对病毒性肝炎，检测特定肝炎病毒的血清学标志物。如甲肝抗体、乙肝两对半、乙肝病毒DNA，丙肝抗体、丙肝病毒RNA，丁肝抗体，戊肝病毒抗体等。

# 肝功能检测

检测肝脏的生化功能，评估肝脏的健康状况。如转氨酶（ALT、AST）水平可反映肝细胞损伤的程度，血清蛋白质检测（包括总蛋白、白蛋白和球蛋白）则用于评估肝脏的合成功能。

# 凝血功能检测

通过检测凝血相关指标来评估肝脏合成凝血因子的能力。包括凝血酶原时间（PT）、凝血酶原活动度、国际标准化比值（INR）、纤维蛋白原、部分凝血活酶时间、凝血酶时间等主要方法。

# 影像学检查

通过影像技术观察肝脏的形态和结构，判断肝脏有无病变。主要包括腹部超声（US）和CT扫描等技术手段。

# 其他早筛方式

包括肝活检以及遗传性肝病基因检测等，通过多种途径实现肝炎早筛。

肝炎早筛行业的特征包括技术壁垒高、市场前景广阔、商业模式明确。

# 技术壁垒高

肝炎早筛行业的一个显著特点是其高度的技术壁垒。这一行业要求企业不仅要掌握先进的生物检测技术，以确保检测结果的准确性和可靠性，还需要不断研发和更新技术，以适应不断变化的肝炎病毒变异和新型肝炎的检测需求。此外，行业内的企业还需遵循严格的监管标准，获得必要的认证和批准，这进一步增加了行业的进入门槛。因此，肝炎早筛行业的参与者往往是那些拥有雄厚研发实力和丰富行业经验的公司，它们能够通过技术创新和优质服务来满足市场需求，从而在竞争激烈的市场中占据一席之地。

# 市场前景广阔

全球及中国市场对肝炎早筛有着巨大需求。鉴于肝炎作为肝癌的主要高风险因素，肝炎早筛市场潜力不容小觑。原发性肝癌在全球及中国的发病与死亡数据，特别是中国承担近半数全球肝癌负担的情况，指出优化高危人群筛查与管理的重要性。全球每年新发病例数表明，肝病存在庞大目标筛查群体。随着健康意识的提高以及政府对肿瘤防治政策的支持，包括对肿瘤早筛的日益重视，肿瘤早筛行业的商业探索将加速，这对肝炎早筛亦是一种正面激励，显示市场需求与政策推动力作为市场扩大的关键因素。

# 商业模式明确

肝炎早筛行业展现了清晰的商业模式框架。下游渠道端主要包括医院、体检中心、直接面向消费者，以及与政府的项目合作。这些模式体现了多样化的市场策略，企业依据自身优势布局肝炎筛查，并结合健康管理服务，以满足不同人群的需求，形成市场差异化。在国内肝炎早筛市场竞争中，价格与渠道推广成为主要瓶颈，这对肝炎早筛行业而言，意味着成本控制、渠道建设和客户教育将是商业化的关键因素。未来，通过与支付方（如医保和商业保险）的合作，以及海外市场的开发，将是进一步拓展商业路径的重要方向。这不仅反映了肝炎早筛企业在市场需求响应上的灵活调整机制，也体现了其长远的战略规划。

# 发展历程

肝炎早筛行业的发展历程可以分为三个主要阶段：1990年代初至2016年的萌芽期，20世纪90年代初，日本率先推行肿瘤高危人群筛查，有效提高了肝癌的早期诊断率，国际社会对肝炎的关注逐渐升温，特别是乙肝和丙肝作为导致肝硬化和肝细胞癌的重要因素，受到了广泛关注；2016年至2018年的启动期，世界卫生组织提出了全球消除病毒性肝炎的目标，中国在李兰娟院士的指导下，通过乙肝疫苗推广和丙肝病毒筛查显著降低了感染者的数量，但仍与世卫组织目标存在差距，海南省启动了乙肝表面抗原和抗体筛查项目并提供专项资金支持；2018年至今的高速发展期，全国多中心、前瞻性万人队列肝癌极早期预警标志物筛查项目（PreCar）启动并公布了先导试验结果，2019年基于循环游离DNA（cfDNA）基因突变联合血液蛋白标志物的液体活检方法（HCCscreen）在早期肝癌筛查方面取得显著成果。未来，随着技术的不断进步和市场需求的增长，肝炎早筛行业将继续保持快速发展，通过技术创新、政府支持和支付方合作，进一步提高筛查的准确性和普及率，为全球肝炎防控做出更大贡献。

# 萌芽期 1990-01-01~2016-01-01

1990年代初至2016年：肝炎早筛行业的萌芽期起始于20世纪90年代，此时，日本大力推行肿瘤高危人群的筛查，这在某种程度上有效提高了肝癌的早期诊断率。在此阶段，国际上对于肝炎的重视逐步上升，而乙肝、丙肝等病毒性肝炎，作为导致肝硬化与肝细胞癌的重要因素之一，开始受到更多关注。

这一时期，早筛技术和理念正处在初步探索和试验阶段。技术手段尚未成熟，公众对早筛的认识和重视程度相对较低。但是，随着医疗技术的逐渐进步及早筛意识的逐步增强，各国政府和专业机构已开始着眼于肝炎及其带来的严重后果，并采取行动。

# 启动期 2016-01-01~2018-01-01

2016年至2018年：进入启动期，世界卫生组织在2016年提出了全球消除病毒性肝炎作为公共卫生威胁的目标。随后国内外开始逐渐认识到了肝癌早筛的紧迫性和重要性。在中国，李兰娟院士指出乙肝疫苗推广和丙肝病毒筛查推进促进了感染者数量显著降低。然而专家也指出，中国乙肝防治与世界卫生组织目标存在差距。为改善这些问题，海南省开展了乙肝表面抗原和抗体筛查，并安排特定资金支持。

启动期内中国部分省份已经开始实施地方性的乙型肝炎规范治疗项目试点方案。同时，在此阶段也有了对于乙型肝炎更加全面的认识。传播途径、预防方法、治疗技术得到广泛宣传与介绍。

# 高速发展期 2018-01-01~至今

2018年至今：随着技术创新和市场需求催化，高速发展期见证了一系列科技突破和制度创新。2018年，全国多中心、前瞻性万人队列肝癌极早期预警标志物筛查项目（PreCar）启动并公布先导试验结果，为提升中国肝癌防控水平提供科学依据。随后，在2019年基于cfDNA基因突变联合血液蛋白标志物的液体活检方法(HCCscreen)在早期肝癌早筛方面取得显著成果。

此时期内产业呈现爆破式增长，政策支持力度加大，技术创新频发。基因检测技术与传统血清标志物检测和影像学检查结合形成“铁三角”模式，在2019年曾经被中国工程院院士呼吁应将肝炎筛查纳入常规体检。此外，“健康肝・中国行”等全国性公益活动推广以提升公众意识，并促进5年生存率提高。

# 产业链下游分析

医疗意识增强带动公众肝炎早筛需求增长，推动下游健康体检服务量价齐升。

肝炎早筛下游参与者有健康体检人群，其中可能包括未被诊断的肝炎患者；以及需要定期筛查的肝炎高危人群。随着定期肝脏体检项目的普及，公众逐渐开始意识到肝炎风险，进而主动参与早期筛查。肝脏检查作为常规项目被广泛纳入健康体检，使得公众能够通过定期体检了解自己的肝脏健康状况。随着对肝脏健康意识的提高，那些在体检中发现可能存在肝炎风险的个体更有可能主动进行肝炎早期筛查。尽管企业定期提供的年度体检已成为常态，但公众对于健康体检的需求已不满足于基础的团体项目，逐渐倾向自费进行更深层次的检查，特别是对于肝炎等关键健康指标的早期筛查。以龙头专业体检机构美年健康为例，从2019年上半年至2024年上半年，个人客户对公司收入的贡献显著增长，占比从 $28 \%$ 提升至 $33 \%$ ，体现个检业务的强劲发展势头。与此同时，客单价也实现了持续稳健的增长，由2019年上半年的499元升至2024年上半年的653元，健康消费端日益旺盛，对高质量健康服务需求也在不断攀升。

中国作为全球乙型肝炎负担最大的国家，面临着肝炎诊治率较低的挑战，未来扩大筛查规模势在必行。

乙型肝炎病毒是全球重要的公共卫生问题，其疾病负担重。世界卫生组织提出到2030年乙肝诊断率和治疗率分别达到 $90 \%$ 和 $80 \%$ 的目标。2023年中国的乙肝诊断率和治疗率分别为 $24 \%$ 和 $15 \%$ ，与WHO的目标存在较大差距，优先考虑提高乙肝诊断和治疗的覆盖率。为进一步缩小目标差距，中华预防医学会感染性疾病防控分会等在2024年提出针对乙肝防控的相关建议，应针对成人进行普遍筛查，建议成人一生至少筛查一次HBV，包括HBsAg、抗HBs和抗-HBc3项，检查价格在100-300元不等；针对高危人群进行HBV标志物检测，如HBV DNA定量等，检查价格约120元。

# 肝炎早筛行业市场规模历史变化的原因如下：

中国是世界上肝炎患者最多的国家之一，患者存在知晓率及诊断率低的问题，肝炎早筛有刚性需求。

中国是世界上肝炎患者数量最多的国家之一，据世界卫生组织统计，截至2022年底，中国约有9,000万慢性乙型肝炎病毒感染者，占全球总数的近三分之一。然而，中国乙肝诊断率低于 $20 \%$ ，现存大量需要早筛的乙肝患者，丙肝患者同样存量巨大，存在知晓率和诊断率低的问题，肝炎早筛具有刚性需求。

生物技术、基因测序技术和人工智能等高新技术的发展，肝炎早筛技术取得了显著进步。

生物标志物的研究和开发为肝炎的早期诊断提供了新的工具，通过检测血液中的特定蛋白质或代谢产物，可以更早地发现肝炎病毒感染的迹象。高通量基因测序技术的应用使得对肝炎病毒的基因组进行快速、准确的分析成为可能，有助于识别病毒的亚型和耐药突变，为个体化治疗方案的制定提供依据。人工智能技术则通过机器学习算法高效分析大量筛查数据，发现潜在的高风险人群，并通过深度学习技术辅助医生解读影像资料，提高早期肝炎、肝癌的检出率，扩大公众对于智肝炎早筛及相关服务的市场需求。

# 肝炎早筛行业市场规模未来变化的原因主要包括：

世界卫生组织目标驱动下，政府大力推动社区筛查覆盖率，预计到2030年肝炎筛查覆盖率将达到90%。

根据WHO的《2016-2021年全球卫生部门战略：病毒性肝炎》报告，目标在2030年前将全球肝炎新发感染减少 $90 \%$ ，肝炎相关死亡减少 $65 \%$ 。为实现这一目标，中国政府采取了一系列措施，包括加强基层医疗卫生机构能力建设、推广社区筛查项目和提高公众健康意识。预计到2030年，通过持续的努力和政策支持，肝炎筛查覆盖率将达到 $90 \%$ ，覆盖率的提升将显著增加对肝炎早筛服务的市场需求。

肝炎筛查项目全面完善，单价水平提升，公众为健康买单意愿增强。

随着新技术的应用和筛查服务的优化，虽然单次筛查的价格可能会有所上升，但整体性价比将大幅提升。例如，高灵敏度的HBV-DNA检测和肝脏纤维化监测等高端服务的推出，将为患者提供更准确、更全面的健康评估。尽管这些服务的单价可能较高，但其带来的健康收益和早期干预的价值远远超过成本。此外，政府将继续通过医保报销、公益筛查项目等方式，减轻低收入群体的经济负担。截至2022年初，通过价格协商，包括中国本土药品在内的8种直接作用抗病毒药物（DAAs）已被纳入基本健康保险，DAAs治疗的费用降至每3个月200-1500美元。B类药物的报销比例为 $70 \%$ ，个人自付费用仅为每3个月150-450美元，大大减轻了患者的经济负担。这使得公众更愿意主动进行筛查，而不必担心因患病带来的经济压力。

肝炎早筛行业呈现以下梯队情况：第一梯队公司有华大基因、金域医学等；第二梯队公司为艾迪康、迪安诊断、达安基因等。

# 肝炎早筛行业竞争格局的形成主要包括以下原因：

肝炎早筛技术平台成熟，检测覆盖度高，样本数量丰富，进一步提高早筛灵敏度和准确性。

第一梯队企业以技术水平和检测灵敏度为导向，通过技术创新，不断打造内生高成长性价值链。金域医学围绕着病毒性肝炎已搭建常规细菌培养、真菌培养、病毒培养等多种技术平台，并与电镜技术平台、病理技术平台等进行密切的技术合作，以不断提高肝炎筛查的技术水平，提升企业的核心竞争力。借助覆盖全国的网络和专家资源，金域医学积累大量肝炎相关的检测数据，截至2018年底，在肝病领域的检测样本量近400万例，并与华为云开展合作，精确地识别肝炎病毒的不同亚型和变异株，提高检测的灵敏度和特异性。

打通产业链一体化，提升业务盈利水平。

第一梯队企业逐渐形成“研产销检”一体化产业链的企业战略布局，实现资源的高效整合和优化配置，形成规模效应。华大基因在上游通过核心子公司华大吉比爱进行体外诊断试剂产品的研产销，推出多款肝炎早筛试剂；在下游，华大基因布局了面向2C的健康管理服务，通过华大互联网医院，进一步贴进终端客户，打开增量市场。

# 肝炎早筛行业竞争格局的变化主要有以下几方面原因：

# 政策重视肝炎等传染病的防控及诊疗率，龙头企业持续布局全国检测范围，扩大影响力。

2021年，国家疾控局联合多个部门发布了深化医疗、医保、医药“三医联动”的工作方案，通过“五加强、一加大、一落实”七项重点任务，全面加强了对肝炎等传染病的宣传教育、综合干预、转介治疗、药品供应、信息管理和检测力度，并落实医保政策，旨在最大限度地减少新发感染，降低疾病流行水平。以广东省为例，该省于2022年启动了《病毒性肝炎早防早治行动方案》，目标是在2026年前将20-70岁人群的乙肝筛查率提升至 $70 \%$ ，并为此投入2.8亿元财政资金。通过政府、医院和检测中心的紧密合作，广东省致力于扩大早期筛查的覆盖范围，提高筛查的质量和效率。与此同时，作为行业的领军企业，金域医学积极响应国家政策，不仅大幅扩展了检测项目，从2017年上市初期的2,500项增加到目前的4,000余项，而且显著增加了研发投入。此外，金域医学与吉利德科学联手，在全国范围内组织了多次丙肝筛查和健康宣教活动，活动覆盖了新疆、河南、湖北等30个省份超过200家医疗机构，成功帮助上万名高风险人群实现了疾病的早期筛查和诊断。

# 普检龙头逐步布局特检业务，行业内竞争激烈。

随着高敏HBV DNA等定量检测在临床中的作用愈发重要，未来将逐步取代传统低敏试剂检测，多家医院肝炎相关体检项目也由定性筛查变为定量筛查，因此为潜在患者提供肝炎高精检测服务是未来行业发展的重要趋势。目前，肝炎普检行业已经处于稳定的竞争格局，行业内企业需要寻求新的技术突破以保持竞争力。艾迪康等普检行业巨头已经开始进行注资肝炎特检行业的战略布局。除了普通的肝炎病毒抗体筛查，艾迪康还增加了肝炎全套13项检测，用于辅助判断肝炎病因，以及自身免疫性肝病抗体检测、基因分析、多种项目诊断肝纤维化情况等。

# 医保改革推动下，行业迎来规模化发展新浪潮，预计行业内集中度将进一步提高。

医保改革的核心方向之一是推行按病种收费的制度。在此背景下，医院的检验中心将面临更加严格的成本控制要求，这将促使独立临床实验室的规模优势得以凸显。一方面，规模较大的检测机构能够通过优化资源配置和提高运营效率来有效降低成本；另一方面，这些机构凭借其强大的市场竞争力和抗风险能力，在面对如安徽省已实施的全国性检测项目集中采购等政策变化时，能够更好地应对挑战。预计此类政策的推广将对小型检测机构构成较大压力，促进行业内资源向大型企业集中，进而推动整个行业结构的优化与升级。
